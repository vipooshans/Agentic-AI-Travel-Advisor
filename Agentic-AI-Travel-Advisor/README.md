# Agentic AI Travel Advisor & Booking System

A full-stack travel advisory platform combining a Flutter mobile app, ASP.NET web API, agentic AI system, and PostgreSQL database.

## Project Structure

| Directory     | Description                          |
|---------------|--------------------------------------|
| `mobile-app/` | Flutter mobile application           |
| `web-app/`    | ASP.NET Core web application & API   |
| `agentic-ai/` | Multi-agent AI travel planning system|
| `database/`   | PostgreSQL migrations, schemas, seed |
| `documentation/` | Architecture & API documentation  |

## Getting Started

See the README in each sub-project for setup instructions.
